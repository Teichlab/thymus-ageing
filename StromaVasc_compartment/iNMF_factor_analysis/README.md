# Thymic fibroblast programmes — final notebooks

The joint iNMF factor analysis of thymic fibroblasts across age (dissociated scRNA-seq + multiome
nuclei), its use across the fibroblast populations, the programme calls that feed the multiome
accessibility analysis, and the projection of the programmes onto the Xenium sections.

Five notebooks, one shared module, no other project code. Kernel `fb_factors`
(pyliger 0.2.4, scanpy 1.11, anndata 0.12, decoupler 2.2).

| notebook | does | reads | writes |
|---|---|---|---|
| `01_gene_basis_and_inputs` | audits the joint object, checks that the mature-adipose programme is captured in nuclei, builds the 3,671-gene basis (shared highly variable genes + marker panels), writes the fit inputs | the joint object, `fb_factor_signatures.csv`, the harmonised annotation | `data/nmf_joint/final/{basis_shared.txt, inmf_input_counts.h5ad, fb_light.h5ad}` |
| `02_iNMF_model_selection_and_atlas` | the fit (`_jobs/fit_inmf.py`), the k sweep (6–18) and λ sweep (0.1–5) scored by target-programme recovery, then the atlas of the 16 factors of the chosen model (k = 16, λ = 5): genes, panel calls, arm balance, covariates, redundancy, private matrices, UMAPs | the fitted models (`data/nmf_joint/inmf` + `_archive`), 01 | `results/final/02_inmf_model/factor_annotation_k16_lam5.csv` + diagnostics |
| `03_factor_usage_by_population` | usage of every programme per fibroblast population (harmonised annotation), scRNA-seq and multiome side by side; cross-modality concordance | model, 01, harmonised annotation | `results/final/03_usage_by_population/`, `plots/final/03_usage_by_population/` |
| `04_programme_calls_for_multiome` | one exclusive label per cell for S1 / S7 / S12 / S15 (z ≥ 0.75 within arm, share ≥ 0.10, highest z wins, else `unassigned`); donor support; the nuclei barcodes for the accessibility analysis | model, 01 | `data/nmf_joint/final/programme_calls_S1_S7_S12_S15.parquet`, `results/final/04_programme_calls/nuclei_barcodes_*.csv` |
| `05_xenium_spatial_scoring` | panel signatures of the 16 programmes scored on donor × morphology-niche pseudobulks (patches, all cells, fibroblast cells), two gates, all 16 and the 4 selected programmes across the eight compartments, age, composition control | model, 01, the Xenium pseudobulk store | `results|plots/final/05_xenium_spatial/` |

`fb_common.py` holds the paths, the factor names, the signature loader, the model-selection
criteria (expected states per programme) and the figure helpers. `METHODS_Fb_factors.md` is the
methods text for the manuscript.

## How to (re)run

The notebooks are generated by `_jobs/nbNN_*.py` (edit the builder, or edit the `.ipynb` and stop
using the builder) and executed inside an LSF job — nothing runs on the login / VS Code host:

```bash
J=/nfs/team205/vk8/projects/thymus_ageing_atlas/FB_Vascular_compartment/notebooks/revisions/final/_jobs
# 01 loads the full object (~7 GB peak, ~2 min); 02-05 take ~4 GB and ~3 min together
bsub -q normal -J fbf01 -n 4 -M 16000 -R "select[mem>16000] rusage[mem=16000]" -o $J/logs/fbf01.%J.log -e $J/logs/fbf01.%J.err $J/run_nb.sh 01
bsub -q normal -J fbf02 -n 4 -M 8000 -R "select[mem>8000] rusage[mem=8000]" -w "done(fbf01)" -o $J/logs/fbf02.%J.log -e $J/logs/fbf02.%J.err $J/run_nb.sh 02 03 04 05
# syntax-only pass (builds the notebooks and compiles every code cell, no execution; ~30 s):
bsub -q normal -J fbfchk -n 1 -M 2000 -R "select[mem>2000] rusage[mem=2000]" -o $J/logs/fbfchk.%J.log -e $J/logs/fbfchk.%J.err "CHECK_ONLY=1 $J/run_nb.sh 01 02 03 04 05"
```

`run_nb.sh NN` rebuilds notebook NN from its builder, compile-checks every cell, executes it in
place and stops on the first error. Any notebook can also be opened on a Jupyter server with the
`fb_factors` kernel.

The model fits are loaded from disk. To refit (one job per setting, ~6 min / ~20 GB each):
`python _jobs/fit_inmf.py <k> <lambda> <out_dir>`; notebook 02 has the loop and `FORCE_REFIT`.
